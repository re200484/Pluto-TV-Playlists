# 🌎 Pluto TV Playlists

Automatically updated **Pluto TV M3U8 playlists** with **XMLTV EPG** for 7 regions.

![Auto Update](https://img.shields.io/badge/Token-Auto%20Updated-brightgreen)

The playlists are regenerated by GitHub Actions and published to the `output/` folder. The raw URLs below always point to the latest version.

### EPG (XMLTV)

Use the file that matches the playlist region:

```text
US: https://raw.githubusercontent.com/re200484/Pluto-TV-Playlists/main/output/plutotv_us.xml
UK: https://raw.githubusercontent.com/re200484/Pluto-TV-Playlists/main/output/plutotv_uk.xml
CA: https://raw.githubusercontent.com/re200484/Pluto-TV-Playlists/main/output/plutotv_ca.xml
DE: https://raw.githubusercontent.com/re200484/Pluto-TV-Playlists/main/output/plutotv_de.xml
FR: https://raw.githubusercontent.com/re200484/Pluto-TV-Playlists/main/output/plutotv_fr.xml
ES: https://raw.githubusercontent.com/re200484/Pluto-TV-Playlists/main/output/plutotv_es.xml
IT: https://raw.githubusercontent.com/re200484/Pluto-TV-Playlists/main/output/plutotv_it.xml
```

In your IPTV player (TiviMate, IPTV Smarters, OTT Navigator, etc.), add the M3U8 URL as the playlist and the XML URL as the EPG source.

> The EPG files are updated together with the playlists. If your player supports a single EPG URL for all regions, you can also use the external [Matt Huisman EPG](https://raw.githubusercontent.com/matthuisman/i.mjh.nz/refs/heads/master/PlutoTV/all.xml).

## ⚙️ How it works

- GitHub Actions runs the scraper on a schedule (hourly).
- The scraper fetches the current Pluto TV channels and refreshes the session token.
- The generated files are committed and pushed to `main`.
- Each update is published as a **single commit**, so the repository history does not grow indefinitely.

No manual intervention is required.

---

## 🍴 Use your own fork

If you want your own copy with your own `clientID`:

1. **Fork** this repository.
2. Open the **Actions** tab and enable the workflows (forks have Actions disabled by default).
3. Edit `config.json` and replace the value of **`clientID`** with a new UUID:
   - Generate one at <https://www.uuidgenerator.net/>.
   - Keep the rest of the file unchanged.
4. Run the **Auto Pluto Update** workflow manually, or wait for the schedule.
5. Use the raw URLs of **your** fork (replace `re200484` with your GitHub username).

> Using your own `clientID` avoids sharing the same Pluto TV session/device identity with everyone else.

## 🖥️ Run locally

Requires Node.js 20 or newer.

```bash
npm install
node index.js
```

The generated files are written to `output/`.
